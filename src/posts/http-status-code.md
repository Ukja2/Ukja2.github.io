상태 코드는 첫 자리 숫자로 대분류를 알 수 있다. 1xx 정보, 2xx 성공, 3xx 리다이렉트, 4xx 클라이언트 오류, 5xx 서버 오류.

## 401 vs 403

- **401 Unauthorized** — 인증 자체가 안 된 상태. "누구세요? 로그인부터 하세요."
- **403 Forbidden** — 인증은 됐지만 권한이 없는 상태. "당신인 건 알겠는데, 이건 못 봅니다."

## 301 vs 302

- **301 Moved Permanently** — 영구 이동. 브라우저/검색엔진이 새 주소를 기억하고 다음부턴 바로 그쪽으로 간다.
- **302 Found (임시 이동)** — 일시적인 이동. 다음 요청에도 원래 주소로 다시 물어본다.

SEO 관점에서 URL을 영구히 바꿨다면 301을, 로그인 후 리다이렉트처럼 상황에 따라 달라지는 경우엔 302/303을 쓴다.

## 자주 보는 코드 모음

| 코드 | 의미 |
| --- | --- |
| 200 | 성공 |
| 204 | 성공했지만 응답 본문 없음 |
| 400 | 요청 자체가 잘못됨 |
| 404 | 리소스를 찾을 수 없음 |
| 429 | 요청이 너무 많음 (rate limit) |
| 500 | 서버 내부 오류 |
| 502 | 게이트웨이가 백엔드로부터 잘못된 응답을 받음 |
| 503 | 서버가 일시적으로 요청을 처리할 수 없음 |
