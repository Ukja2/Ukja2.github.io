## 저축은행과 시중은행의 차이

시중은행은 신용도가 높은 기업이나 개인에게 돈을 빌려주지만, 저축은행은 그 정도의 신용을 갖추지 못한 소상공인·개인사업자에게 맞는 상품을 취급하는 은행이다.

## 자주 쓰는 업무 용어

| 용어 | 설명 |
| --- | --- |
| 수신 | 고객이 돈을 맡기면 이자를 약속하고 받아두는 업무 (신용을 받는 일) |
| 여신 | 고객에게 돈을 빌려주고 이자를 받는 업무 (신용을 주는 일) |
| 대손 | 빌려준 돈을 받지 못한 채 손실로 처리하는 것 |
| 원장 | 고객의 계좌 잔액, 거래 내역, 고유 정보 등 모든 금융 거래가 기록되는 최종 장부이자 마스터 데이터베이스 |
| 전문 | 은행 시스템끼리 주고받는 데이터 양식. 네트워크의 페이로드(payload)와 같은 역할을 하며, 거래정보·송수금자·잔액 등 다양한 항목을 담는다 |
| CMS | 금융결제원과 은행이 공동으로 제공하는 자동이체 서비스 |
| 오픈뱅킹 | 다른 은행 계좌를 우리 앱에서 조회·이체하는 서비스. 금융결제원 공동망을 통해 연결된다 |
| 가상계좌 | 실제 계좌가 아닌 식별번호로 입금을 인식하는 계좌 |
| 이상거래탐지시스템(AML) | 정상 거래 패턴을 학습하고 평소와 다른 거래를 잡아내는 시스템. 예: 대구에 사는 고객이 평소와 달리 새벽 3시에 해외 IP로 큰 금액을 이체하면 즉시 차단하고 확인 전화를 건다 |
| PF | 부동산개발사업 대출 |
| KYC | 본인 확인 절차 |
| 자점감사 | 은행의 부서에서 처리한 업무가 규정에 맞게 이루어졌는지 자체적으로 점검·감사하는 내부 통제 제도 |
