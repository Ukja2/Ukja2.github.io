`ls -l`을 치면 나오는 `-rwxr-xr--` 같은 문자열, 매번 헷갈려서 정리한다.

## 세 그룹, 세 권한

권한은 **소유자(user) / 그룹(group) / 그 외(other)** 세 그룹에 대해 각각 **읽기(r) / 쓰기(w) / 실행(x)** 권한을 표시한다.

```
-rwxr-xr--
 └┬┘└┬┘└┬┘
  │  │  └─ other: r--
  │  └──── group: r-x
  └─────── user : rwx
```

## 숫자로 표기하기

r=4, w=2, x=1을 더해서 한 자리 숫자로 표현한다.

- `rwx` = 4+2+1 = **7**
- `r-x` = 4+0+1 = **5**
- `r--` = 4+0+0 = **4**

그래서 `chmod 755 파일`은 소유자는 전부 가능(rwx), 그룹과 나머지는 읽기+실행만 가능(r-x)하다는 뜻이다.

## 자주 쓰는 조합

| 숫자 | 의미 | 주로 쓰는 곳 |
| --- | --- | --- |
| 644 | 소유자 읽기/쓰기, 나머지 읽기만 | 일반 파일 |
| 755 | 소유자 전체, 나머지 읽기/실행 | 실행 파일, 디렉터리 |
| 600 | 소유자만 읽기/쓰기 | 비밀키, 설정 파일 |
