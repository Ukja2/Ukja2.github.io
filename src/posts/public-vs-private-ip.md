## 공인 IP(Public IP)란

**인터넷 전체에서 단 하나만 존재하는 주소**다. ISP(통신사)가 부여하며, 전 세계 어디에도 겹치지 않는다. 그래서 외부 인터넷과 직접 통신할 수 있고, 인터넷에서 나를 식별하는 주소 역할을 한다.

## 사설 IP(Private IP)란

**하나의 내부 네트워크(집, 회사 등) 안에서만 유효한 주소**다. 인터넷에 직접 노출되지 않으며, 그 네트워크를 벗어나면 아무 의미가 없다.

그래서 서로 다른 네트워크라면 같은 사설 IP를 중복해서 써도 상관없다. 집집마다 공유기 기본 주소가 `192.168.0.1`인 이유가 여기 있다.

사설 IP를 쓰는 기기가 인터넷에 나갈 때는 공유기가 **NAT(Network Address Translation)** 을 통해 사설 IP를 공인 IP로 바꿔서 내보낸다.

## 굳이 사설 IP를 쓰는 이유

집에 있는 컴퓨터, 스마트폰, TV, IoT 기기까지 전부 공인 IP를 하나씩 줘도 될 것 같은데, 실제로는 그렇게 하지 않는다. 이유는 크게 세 가지다.

- **IPv4 주소 고갈**: IPv4 주소는 약 43억 개뿐이라 전 세계 모든 기기에 공인 IP를 하나씩 줄 수 있는 양이 아니다. 사설 IP를 쓰고 NAT으로 공인 IP 하나를 여러 기기가 나눠 쓰게 하면, 훨씬 적은 공인 IP로도 무한히 많은 내부 기기를 운용할 수 있다.
  - 그럼 결국 기기 1대당 공인 IP 1개가 필요한 거 아닌가 싶을 수 있는데, 아니다. 공인 IPv4 주소는 기기마다 하나씩 필요한 게 아니다. 가정에서는 인터넷 사업자로부터 공유기의 **WAN 측**에 공인 IP 하나를 할당받고, 공유기는 그 아래 내부 기기들에게 사설 IP를 할당한다. 이후 NAT를 통해 여러 내부 기기가 하나의 공인 IP를 공유하여 인터넷과 통신할 수 있다.
- **보안**: 사설 IP는 인터넷에 직접 노출되지 않는다. 외부에서 내 스마트폰이나 프린터에 곧바로 접근할 방법이 없으니, 공격 표면 자체가 줄어든다. 공유기가 방화벽처럼 내부망을 한 겹 가려주는 셈이다.
- **관리 편의성/비용**: 공인 IP는 ISP가 제한적으로 부여하고 비용도 들지만, 사설 IP는 네트워크 관리자가 내부에서 마음대로 자유롭게 할당·재구성할 수 있다. 기기를 추가하거나 네트워크 구조를 바꿀 때 ISP와 협의할 필요가 없다.

## 구별법: 사설 IP 대역(RFC 1918)

아래 범위에 속하면 사설 IP, 아니면 공인 IP다.

| 클래스 | 대역 |
| --- | --- |
| A | 10.0.0.0 ~ 10.255.255.255 |
| B | 172.16.0.0 ~ 172.31.255.255 |
| C | 192.168.0.0 ~ 192.168.255.255 |

추가로 자주 마주치는 특수 대역도 함께 알아두면 좋다.

- **127.0.0.0/8**: 루프백(loopback) — 자기 자신을 가리키는 주소, `localhost`
- **169.254.0.0/16**: APIPA — DHCP로 IP를 못 받았을 때 자동으로 할당되는 링크 로컬 주소
