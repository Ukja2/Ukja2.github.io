둘 다 "격리된 실행 환경을 만든다"는 목적은 같지만 구현 방식이 다르다.

## 가상머신(VM)

하이퍼바이저 위에 **OS 커널을 통째로** 올린다. 그래서 무겁고 부팅도 느리지만, 완전히 독립된 커널을 가지므로 격리 수준이 가장 높다.

## 컨테이너

호스트의 커널을 **그대로 공유**하고, 프로세스/네트워크/파일시스템만 네임스페이스로 격리한다. 그래서 이미지가 가볍고 시작도 몇 초면 끝난다.

## 비교

| | VM | 컨테이너 |
| --- | --- | --- |
| 격리 단위 | 하드웨어 수준 | 프로세스 수준 |
| 커널 | 각자 별도 | 호스트와 공유 |
| 부팅 속도 | 수십 초~분 | 1초 내외 |
| 이미지 크기 | 수 GB | 수십~수백 MB |

## 언제 뭘 쓰나

완전히 다른 OS가 필요하거나 강한 보안 격리가 필요하면 VM, 배포 속도와 리소스 효율이 중요하면 컨테이너를 쓴다. 요즘은 클라우드 VM 위에 컨테이너를 올리는 조합도 흔하다.
