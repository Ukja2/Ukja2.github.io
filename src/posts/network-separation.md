## 망분리(Network Separation)란

**업무용 내부망과 인터넷(외부망)을 물리적 또는 논리적으로 완전히 분리해서, 인터넷을 통한 보안 위협이 업무 시스템에 도달하지 못하게 하는 방식**이다. 물리적 장비·네트워크를 직접 구성하는 온프레미스 환경을 기준으로 설명한다.

인터넷에 연결된 PC는 악성코드, 피싱, 해킹 시도 등에 항상 노출돼 있다. 업무 시스템(고객 정보, 금융 거래 데이터, 내부 문서 등)이 그 PC와 같은 네트워크에 있으면, PC 한 대만 뚫려도 업무 시스템 전체가 위험해진다. 망분리는 이 연결 경로 자체를 끊어서, 인터넷 쪽에서 무슨 일이 생기든 업무망에는 애초에 닿을 수 없게 만든다. 국내 금융권·공공기관에서는 법적으로 의무화된 경우가 많다.

## 실제 구조: 네트워크가 두 개로 나뉜다

물리적 망분리를 하면 회사 안에 완전히 분리된 두 개의 네트워크가 생긴다.

```
[업무망]  ── 사내 서버, 사내 메신저, 내부 DB, 프린터 등 (인터넷 연결 X)
[인터넷망] ── 인터넷 전용 PC, 웹서핑, 외부 메일 등 (업무망과 연결 X)
```

![업무망과 인터넷망의 직접 연결은 차단하고, 망연계 솔루션을 통해 검사된 파일만 오가게 한 망분리·망연계 구조도](/assets/posts/network-separation/network-separation-architecture.webp)

- **업무망 내부 통신은 정상 작동한다**: 사내 서버 접속, 파일 공유, 사내 메신저, 결재 시스템 같은 건 업무망 자체가 하나의 완결된 LAN이라 아무 문제 없이 동작한다. 이 LAN에 그냥 **인터넷으로 나가는 문이 없을 뿐**이다.
- **인터넷이 필요하면 다른 망(다른 PC)에서**: 웹서핑, 외부 메일, 자료 검색처럼 인터넷이 필요한 업무는 물리적으로 완전히 분리된 인터넷 전용 PC에서 처리한다. 직원 책상에 PC가 두 대(업무용 + 인터넷용) 놓여 있는 회사를 본 적 있다면, 그게 물리적 망분리의 실제 모습이다.

## 흔한 오해: LAN 통신도 인터넷이 있어야 되는 거 아닌가?

아니다. **인터넷과 LAN 통신은 완전히 다른 층위**다.

- **인터넷**: 전 세계에 흩어진 수많은 네트워크를 서로 연결해주는 광역망(WAN). ISP가 우리 네트워크를 이 망에 연결시켜준다.
- **LAN**: 같은 건물/사무실 안에서 스위치나 공유기로 직접 연결된 로컬 네트워크. 그 안의 기기들끼리는 인터넷을 전혀 거치지 않고 통신한다.

L2 스위치에 전원을 넣고 기기들을 랜선으로 꽂기만 해도, 스위치는 각 포트에서 오가는 트래픽을 보고 MAC 주소를 자동으로 학습해서 프레임을 정확히 전달해준다. 여기에 인터넷, 공유기, ISP는 전혀 필요 없다. IP 기반 통신(핑, 파일 공유 등)을 하려면 기기들끼리 같은 대역의 IP만 맞춰주면 되는데, 이것도 고정 IP를 직접 설정하거나 사설 DHCP를 쓰면 되지 인터넷과는 무관하다.

즉 업무망은 인터넷 없이도 완전하게 동작하는 독립된 네트워크이고, 망분리는 이 업무망과 인터넷망 사이의 연결만 끊어놓은 것이다.

## 물리적 망분리 vs 논리적 망분리

| | 물리적 망분리 | 논리적 망분리 |
| --- | --- | --- |
| 구현 방법 | PC/네트워크 장비 자체를 완전히 별도로 구성 (KVM 스위치 등) | 가상화(VDI 등)로 하나의 물리 환경 안에서 논리적으로 분리 |
| 사용자 경험 | 업무용 PC, 인터넷용 PC 두 대를 따로 사용 | PC 한 대에서 화면 전환/가상 데스크톱으로 전환 |
| 비용/공간 | 높음 (PC·회선 이중 구축) | 상대적으로 낮음 |
| 보안 수준 | 매우 높음 (물리적으로 연결 자체가 없음) | 높음 (가상화 계층이 뚫리면 위험 존재) |

## 망연계(Network Linkage)란

망분리로 끊어놓은 두 망 사이에서, 업무상 데이터를 옮겨야 할 때 파일을 검사해서 중계해주는 통제된 통로다. 대표적으로 망연계 솔루션[^1]이나 중계 서버[^2]를 두고, 그 장비를 통과한 파일만 반대편으로 전달한다.

[^1]: 망연계 솔루션: 분리된 네트워크 사이에서 보안성을 유지하면서 안전하게 데이터를 주고받을 수 있도록 돕는 시스템
[^2]: 중계 서버: 두 망 사이에 위치해서 요청이나 파일을 대신 받아 검증한 뒤 전달해주는 서버.

## VPN·DMZ·망연계, 뭐가 다른가

셋 다 "분리된 네트워크를 안전하게 넘나든다"는 점은 비슷하지만, 목적과 대상이 다르다.

| 구분 | VPN, ZTNA 등 (접근 방식) | DMZ (구간 격리) | 망연계 (데이터 연동) |
| --- | --- | --- | --- |
| 핵심 목적 | 외부 사용자가 사내망에 접속하기 위함 | 외부 공개용 서버를 안전하게 격리하기 위함 | 분리된 두 네트워크 간에 안전하게 파일을 주고받기 위함 |
| 주요 대상 | 재택근무자, 외주 관리자, 출장 직원 | 웹서버, 메일서버, DNS 서버 | 내부망 업무 PC ↔ 외부 인터넷망 PC |
